API UnoFive

Utilisez nos données sur les catastrophes en Afrique (base EM-DAT, 2000-2026) dans vos propres projets : analyses, cartes, tableaux de bord, applications. L'accès est gratuit ; il faut simplement un compte et une clé d'API.

Obtenir une clé

  1. 1

    Créez un compte gratuit, ou connectez-vous si vous en avez déjà un.

  2. 2

    Ouvrez Mon profil (menu en haut à droite), section Clé d'API, puis cliquez sur Générer ma clé.

  3. 3

    Copiez la clé tout de suite : elle n'est affichée qu'une seule fois. Elle ressemble à uf_4kT9…. Si vous la perdez, générez-en une nouvelle.

Premier appel

Toutes les adresses commencent par :

Envoyez votre clé dans l'en-tête X-API-Key de chaque requête. Exemple : les catastrophes du Sénégal en 2020.

Erreurs

En cas de problème, l'API renvoie un code HTTP et un message en français :

400Un paramètre obligatoire manque ou est mal écrit.
401Clé absente, mal recopiée ou révoquée. Vérifiez l'en-tête X-API-Key.
404L'élément demandé n'existe pas (par exemple un fid inconnu).
500Erreur de notre côté. Réessayez plus tard ou contactez-nous.

Comprendre les champs

disnoNuméro unique de la catastrophe dans EM-DAT.
fidIdentifiant du pays dans notre base.
deathsNombre de morts.
total_affectedPersonnes touchées au total : blessés + sinistrés + sans-abri.
damage_usdDégâts en milliers de dollars US (125000 = 125 millions $).
cpiIndice des prix de l'année, utile pour comparer des montants d'années différentes.
